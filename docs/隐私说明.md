# Glyph 隐私说明

更新日期：2026-11-06　｜　适用版本：0.1.1

## 一句话

Glyph 是本地软件：没有账号、没有云端数据库、不上传你的学习数据。只有你主动发消息时，内容才会发给你自己配置的模型服务商。

## 一、存在你电脑上的数据

位置：`文档\Glyph`（可在设置里改）

| 数据 | 用途 |
|---|---|
| 会话记录 | 对话历史、批改结果 |
| 计划 / 词书 / 背词进度 | 学习功能 |
| 记忆 | Agent 记住的偏好与错题 |
| 模型配置与 API Key | 连接你选择的模型服务 |

- 这些文件**只在本机**，Glyph 没有服务器收集它们；
- API Key 保存在本机配置文件中，请勿把该文件夹发给别人。

## 二、什么会离开你的电脑

1. **你发给模型的内容**：消息、图片、批改请求，会发给你在设置里选择的模型服务商（例如阿里云百炼，或你自己配置的中转地址）。发送内容受该服务商的隐私政策约束。
2. **联网搜索**（如果使用）：查询词会发给模型服务商的联网搜索能力。

除此之外没有其他上传：没有统计、没有埋点、没有崩溃上报。

## 三、日志

- 位置：`%APPDATA%\Glyph\logs`；
- 内容：程序启动、接口请求路径、错误堆栈；
- 用途：排查故障；日志留在本机，**不会自动上传**。只有你主动发给开发者时才会离开电脑。
- 日志可能包含接口路径与错误信息，分享前可自行检查。

## 四、第三方组件

- 界面框架 Electron / React；
- 本地词典数据来自 ECDICT（开源词典项目）；
- 字体 Montserrat（SIL Open Font License）。

## 五、你的控制权

- **清空记忆**：设置 → 存储与备份 → 清空记忆（先进回收站，可再永久清理）；
- **删除全部数据**：关闭 Glyph，删除 `文档\Glyph` 文件夹；
- **卸载**：设置 → 应用 → 卸载 Glyph（不会自动删数据）。

## 六、联系

如对隐私有疑问，请通过项目仓库的 Issue 联系开发者。
