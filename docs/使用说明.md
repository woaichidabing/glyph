# Glyph 使用说明（0.1.1）

## 一、安装

1. 双击 `Glyph-Setup-0.1.1.exe`。
2. Windows 会提示「未知发布者」——当前版本没有购买代码签名证书，这是正常现象。
   点「更多信息」→「仍要运行」。
3. 按提示下一步即可；安装不需要管理员密码，装到当前用户目录。
4. 装好后桌面会有 Glyph 图标。

## 二、第一次打开

- 如果还没有配置模型，会出现欢迎页：填一个千问（DashScope）的 API Key，点「保存并继续」。
- 不想现在配：点「跳过」，之后在「设置 → 模型」里配。
- 已经有 Key 的老用户不会看到欢迎页。

## 三、四个工作区

| 入口 | 干什么 |
|---|---|
| 新对话 | 发英文句子/作文，得到批改、逐条讲解；也可以发图片 |
| 词典 | 查单词：音标、释义、例句、词形；查过的词会留记录 |
| 背词 | 选词书、按计划背单词、做一遍过判卷、看错题本 |
| 计划 | 定目标、排周节奏、每天任务；没做完会顺延到第二天 |

## 四、设置

左下角「设置」：

- **模型**：接模型来源（官方或中转）、拉取模型清单、分配角色。
- **外观**：主题、字号、行宽、动效开关等；关闭窗口后也会记住。
- **存储与备份**：数据位置、占用、迁移；记忆与记忆回收站；运行日志。

## 五、关窗与退出

- 点右上角 × **不会退出**，只是缩到托盘（右下角图标）；
- 单击/双击托盘图标：重新打开；
- 右键托盘图标：打开 Glyph / 重启后端 / 打开日志文件夹 / 退出；
- 要真正退出，用托盘菜单里的「退出」。

## 六、数据在哪

默认：`文档\Glyph`（即 `C:\Users\你的用户名\Documents\Glyph`）

里面包括：会话、计划、词书与进度、记忆、模型配置。

- 备份：整个文件夹复制走即可；
- 换电脑：把文件夹放到新电脑同一位置；
- 迁移：设置 → 存储与备份 → 更改位置。

## 七、卸载

设置 → 应用 → 已安装的应用 → 搜 Glyph → 卸载。

卸载**不会删除** `文档\Glyph` 里的学习数据；要彻底清掉请手动删除该文件夹。

## 八、常见问题

**问：词典查不到词？**
答：0.1.0 的安装包有词典缺失问题，0.1.1 已修复。请确认设置页版本是 0.1.1。

**问：打开后一片空白 / 提示后端没起来？**
答：点弹窗里的「查看日志」，把 `%APPDATA%\Glyph\logs` 里的文件发给开发者。

**问：杀毒软件报毒？**
答：Electron 应用未签名时可能被误报。可先把安装包加入信任，或把日志和截图发给开发者做误报申诉。

**问：怎么确认版本？**
答：设置 → 存储与备份 → 最底部「设置保存在本机 · 版本 0.1.1」。
